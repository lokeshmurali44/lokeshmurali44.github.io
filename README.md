# Lokesh Murali Portfolio

Portfolio website for Lokesh Murali, a design leader with 12+ years of
experience across fintech, Web3, healthcare, and B2B SaaS.

## Run locally

Install dependencies:

```bash
npm install
```

Serve the project with any static web server, then open `index.html` through
that server.

For example:

```bash
npx serve .
```

## Built with

- HTML and CSS
- JavaScript
- GSAP and ScrollTrigger
- Lenis
- Swiper
